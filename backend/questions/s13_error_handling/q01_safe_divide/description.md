Create a function that divides two integers. If the divisor is 0, return 0 and the string "division by zero". Otherwise return the result and an empty string.

Expected function:
func SafeDivide(a, b int) (int, string) {}

Examples:
SafeDivide(10, 2) -> 5, ""
SafeDivide(10, 0) -> 0, "division by zero"
