Convert a digit character (rune) to its integer value WITHOUT using any library.

Hint: Subtracting '0' from a digit rune gives its numeric value. For example: '5' - '0' = 5.

Expected function:
func CharToDigit(c rune) int {}

Examples:
CharToDigit('0') -> 0
CharToDigit('7') -> 7
CharToDigit('9') -> 9
