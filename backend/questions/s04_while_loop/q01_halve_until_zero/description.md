Create a function that takes an integer `n`. Using a while-style loop (`for n > 0`), divide the number by 2 in each iteration and count the divisions to reach 0. Return the count.

Expected function:
func CountDivisions(n int) int {}

Examples:
CountDivisions(10) -> 4  // 10->5->2->1->0
CountDivisions(1) -> 1
