Create a function that takes an integer `limit`. Keep adding numbers (1 + 2 + 3 + ...) until the sum is greater than or equal to the `limit`. Return the last number added.

Expected function:
func SumUntil(limit int) int {}

Examples:
SumUntil(10) -> 4  // 1+2+3+4=10
SumUntil(20) -> 6  // +5=15, +6=21
